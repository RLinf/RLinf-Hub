# 中文写作规范

中文 README 应当读起来像一位以中文为母语的工程师写给同行的技术文档，而不是英文 README 的译文。本规范适用于 RLinf-Hub 的所有中文 README、PR 描述和评审意见。

## 先理解，再用中文写

中英文页面保持结构一致：章节、命令、配置项、数字和链接都相同，但句子不必逐句对应。严禁直接机翻或逐句直译。动笔前先理清这一段要告诉读者什么，再按中文习惯组织句子——自由拆句、合句、调整语序，删掉英文句式残留的虚词和过渡词。

- 英文：A self-contained, inference-only RLinf-Hub adapter for the official `lerobot/smolvla_base` checkpoint.
- 翻译腔：一个自包含、仅用于推理的 RLinf-Hub 适配器，面向官方 `lerobot/smolvla_base` checkpoint。
- 自然中文：本目录提供官方 `lerobot/smolvla_base` 权重的 RLinf-Hub 推理适配实现，独立运行，不修改核心 RLinf 代码。

## Markdown 排版

- 中文句子使用全角标点：，。、；：？！“”（）——……。整句都是英文时保留半角标点。
- 引号统一用 “”，嵌套时用 ‘’，不用「」。
- 中文与英文、中文与数字之间加一个半角空格，例如：`在 2 张 A100 上运行 BF16 推理`。数字与单位之间也加空格（`80 GB`、`250 ms`），`%` 和 `°` 前不加。
- 全角标点前后不加空格。
- 并列项用顿号分隔：LIBERO、ManiSkill、RoboTwin。
- 英文专有名词保持原有大小写（GitHub、PyTorch、Hydra、LeRobot），英文词不加中文语境下的复数（写“多个 worker”，不写“多个 workers”）。
- **严禁在中文段落或列表项中间手动换行**：GitHub 渲染 Markdown 时会把段内换行变成空格，导致汉字之间出现多余空隙。每个中文段落和列表项在源文件里保持单行。

## 术语

- 代码里的名称保留原文不翻译：配置项、命令、参数、脚本名、环境变量、模型名、环境名。
- 工程师日常直呼英文的词保留英文：policy、rollout、worker、actor、critic、checkpoint、adapter、config、endpoint、API。
- 已有通行中文说法的用中文：显存、训练、推理、微调、数据集、权重、配置项、归一化、契约（仅用于规范接口时，日常优先说“接口约定”或“输入输出规范”）。
- 同一个概念全文只用一个词，不在“环境”“仿真器”“模拟器”之间来回切换。

## 句子与语气

- **说人话、重易读**：用同行一眼能看懂的平实中文把事情讲清楚；口头给同事讲都不会这么说的句子直接重写。
- 一句话说一件事，分句尽量不超过 40 字；一逗到底的长句拆成短句。
- 用主动句，让执行动作的一方做主语：“脚本读取配置文件”，不写“配置文件由脚本读取”。
- 删掉空动词：“对模型进行评估”写成“评估模型”，“实现了对多卡的支持”写成“支持多卡”。
- 去掉英文连接词直译：
  - `when`：多数“当……时”可改为“……后”“……时”或直接删去。
  - `for` / `regarding`：“对于每个环境来说”写成“每个环境”。
  - `through` / `by`：“通过……的方式”改成直接说怎么做。
  - `allow` / `enable`：“允许你……”“使……能够……”写成“可以……”。
  - `based on`：“基于……”只在确实表示底层依赖时用，其余改用“用”“按”“根据”。
- 去掉多余的“一个”“该”“其”“此”；指代不清时直接重复名词。
- 不用“您”，称呼读者用“你”或省略主语。
- 不夸张（不用“强大”“无缝”“完美”“最先进”“一站式”），不用“值得注意的是”“需要注意的是”，不用“本节将介绍”。
- 避免反复正反面对比（“这不是 A，不是 B，而是 C”“并非……而是……”），直接说明支持什么、怎么做。

## 常见翻译腔对照

| 翻译腔 | 自然中文 |
|---|---|
| 支持的契约 | 支持范围与接口规范 |
| 该适配器直接调用上游实现，而不是复制代码。 | 适配器直接调用上游实现，不复制模型代码。 |
| 当你安装完依赖后，运行以下命令。 | 安装依赖后，运行以下命令。 |
| 对模型进行推理测试。 | 运行模型推理测试。 |
| 值得注意的是，显存至少需要 40 GB。 | 显存至少需要 40 GB。 |
| 它允许你在多个 Ray worker 中注册模型。 | 可以在每个 Ray worker 中自动注册模型。 |

## 自查

- [ ] 遮住英文 README，中文 README 依然流畅自然，像中文工程师直接写出来的。
- [ ] 全文没有“您”“值得注意的是”“「」”；“进行”“被”“当……时”只留在必要处。
- [ ] 中英文、中文与数字之间有空格，中文句中没有半角标点，段落和列表项没有手动折行。
- [ ] 命令、配置项、版本、数字和链接与英文版完全一致。
